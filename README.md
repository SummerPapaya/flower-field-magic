# 花田魔法 · Flower Field Magic

举起手机相机，点一下、滑一道，花就在你身边开成一片花田。花固定在真实的地面或桌面上，可以绕着走、蹲下来看，再拍一张照片。

纯网页，不用装 App，在手机浏览器里打开就能用（目前主要在 iPhone Safari 上测试）。

## 能做什么

- **轻触屏幕，开出花海**：点一下或滑一道，花从手指落下的地方向外依次开放；划过地平线的部分会变成飘在空中的花。
- **花留在原地**：AR 世界追踪把花“种”在真实的地面上，走动、转身、切到别的 App 再回来，花都在原处。AR 准备好之前先用陀螺仪，花跟着视线转动。
- **五套花种**

  | 色卡 | 花 |
  |---|---|
  | 月夜 | 喜林草、绣球、铃兰 |
  | 春日 | 波斯菊、雏菊、向日葵、小苍兰 |
  | 花田 | 以上几种加粉郁金香，混种在一起 |
  | 盛放 | 六色花毛茛、六色郁金香、红玫瑰 |
  | 单种 | 只开其中一种 |

- **种在地面或桌面**：桌面模式下花更小，适合在桌上开一小丛。
- **随手调**：笔刷（花片 / 小簇）、草（有 / 无）、茎叶、密度；双指缩放可以调新开的花的大小，也可以放大画面。
- **拍照**：快门键拍下当前画面，可以存到相册或直接分享。
- **中文 / English**：默认跟随系统语言，开场页右上角可以切换。

## 隐私

相机画面只在你的手机上处理，不上传，也不存到服务器；没有统计和追踪。照片只在你点“保存 / 分享”时交给系统。

## 技术

- React 19、TypeScript、Vite，3D 用 three.js。
- **花田引擎**：每种花用实例化渲染，一个变体一次绘制；开放、生长、风都在顶点着色器里算，CPU 每帧只更新时间。一株花约 200 到 900 个三角形，手机上同屏几十万个三角形仍然流畅。超出预算时，多出来的花会陆续枯萎，不会整片消失。
- **花的造型**：全部是程序生成的几何，不用贴图，颜色写在顶点上。
- **AR**：8th Wall Engine 的 SLAM 世界追踪，外加自己写的位姿过滤器。它把朝向锁在陀螺仪上，过滤跳变和慢漂，手机放平时冻结位置，并用小死区去掉静止时的抖动。切 App 回来时，再按指南针把花田转回原来的方向。
- **开场页**：一幅实时的水彩画，用原生 WebGL 画出湿画法的底色、被风吹动的花、纸纹和笔触；标题是手写字。

## 本地开发

```bash
npm install
npm run dev          # 开发服务器
npm run build        # 类型检查并构建到 dist/
npm run preview      # 本地预览构建结果
```

手机上测试需要 HTTPS，而且要测构建后的版本（开发服务器在手机切到后台后会自动刷新页面）。真机测试用**测试构建**，它带着下面的 `?debug` 功能；可以用 Cloudflare 的快速隧道把本地预览开放给手机：

```bash
npm run build:lab && npm run preview:lab -- --port 5180
cloudflared tunnel --protocol http2 --url http://localhost:5180
```

正式构建（`npm run build`、`npm run deploy`）里没有任何测试功能，打包时整段去掉。

地址参数：

| 参数 | 作用 |
|---|---|
| `?lang=en`、`?lang=zh` | 指定界面语言 |
| `?debug` | 只在开发服务器和测试构建里有：显示版本和帧率，“发送”把诊断数据和截图存到本机的 `probe/reports/`（不进仓库） |
| `?fakecam` | 电脑上调试时用模拟相机画面（只在开发服务器上有效） |
| `?ar=force` | 在电脑上走一遍切换到 AR 的流程（只在开发服务器上有效） |

`/meadow-lab.html` 是花田实验页：`?specimen=tulip&view=特写` 看单种花的特写，`?pre=盛放&view=近` 看整片花田。

## 部署

纯静态站点，`wrangler.jsonc` 把 `dist/` 配置为 Cloudflare Worker 的静态资源：

```bash
npm run deploy
```

## 目录

- `src/screens/`：开场页、相机页
- `src/art/`：开场页的水彩画和手写标题
- `src/engine/`：花田引擎（`meadow.ts` 实例化渲染，`species.ts` 花的造型，`field.ts` 手势变成花，`stages.ts` 陀螺仪和 AR 两种舞台及位姿过滤器）
- `src/lib/`：权限申请、中英文文案（`i18n.ts`）等
- `src/lab/` 和 `meadow-lab.html`：花田实验页（只在开发时用）
- `docs/`：README 用的图

## 已知限制

- 网页 AR 的精度有限：快速移动、手机放平、离桌面很近时，花田可能轻微漂移，桌面模式比地面模式明显。
- 没有遮挡：手或物体挡在花前面时，花仍然画在上面。
- 主要在 iPhone 的 Safari 上测试过，Android 和其他浏览器还没有系统地测。
- AR 引擎约 2 MB，网络慢时第一次加载需要一些时间；加载完之前先用陀螺仪模式。
